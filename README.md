# Conceitos de Arquitetura de Software

Projeto de site institucional desenvolvido para apresentar conceitos, vantagens, desafios e impactos de arquitetura de software, com foco em artigos de referência como Monolith First, Patterns of Legacy Displacement e GUI Architectures.

## Objetivo

Este projeto tem como finalidade:
- apresentar os principais conceitos de arquitetura de software;
- explorar estratégias e padrões discutidos por Martin Fowler;
- divulgar informações de forma visual e didática;
- facilitar a compreensão de temas relacionados à gestão de projetos e arquitetura.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages (para hospedagem local/estática, quando aplicável)

## Estrutura do projeto

- `index.html` - página inicial
- `monolithFirst.html` - artigo sobre Monolith First
- `legacyDisplacement.html` - artigo sobre Patterns of Legacy Displacement
- `guiArchitectures.html` - artigo sobre GUI Architectures
- `css/` - arquivos de estilo
- `js/` - scripts do projeto
- `img/` - imagens e recursos visuais

## Funcionalidades

- Layout responsivo
- Menu de navegação entre artigos
- Seletor de idioma com suporte para português, inglês, espanhol e mandarim
- Estilo visual consistente com tema escuro
- Estrutura estática simples e fácil de manter

## Uso

1. Abra o arquivo `index.html` em um navegador.
2. Navegue pelos artigos disponíveis.
3. Use o seletor de idioma para alternar entre as versões do site.
